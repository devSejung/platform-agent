# PlatformClaw v2026.6.21

Date: 2026-06-21

## 추가

- 에이전트가 만든 이미지와 HTML 결과물을 채팅 안에서 바로 미리 볼 수 있습니다.
- 이미지나 HTML 미리보기를 선택하면 집중 보기 화면에서 크게 확인하고 바로 내려받을 수 있습니다.
- Skill Hub에서 지식, 자동화, 유틸리티 등 카테고리별로 스킬을 찾을 수 있습니다.
- 스킬을 등록하거나 수정할 때 표시 이름, 설명, 카테고리, 아이콘을 설정할 수 있습니다.

## 변경

- Skill Hub의 카드와 상세 화면에서 스킬 아이콘, 카테고리, 설명을 한눈에 확인할 수 있도록 구성을 개선했습니다.
- 스킬 소유권 이전 화면에서 대상 직원 검색과 선택 상태를 더 명확하게 확인할 수 있습니다.
- 로그인 화면의 mascot이 화면 전체의 포인터 위치와 입력 중인 필드에 자연스럽게 반응하도록 개선했습니다.

## 수정

- 채팅에서 이미지와 HTML 결과물이 화면 크기에 맞춰 안정적으로 표시되도록 레이아웃을 개선했습니다.
- 로그인 화면 구성이 늦게 표시되는 경우에도 mascot 상호작용이 정상적으로 연결되도록 개선했습니다.
