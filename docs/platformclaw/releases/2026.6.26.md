# PlatformClaw v2026.6.26

Date: 2026-06-26

## 추가

- Knox에서 `/skillhub help`와 `/skillhub help ko`로 Skill Hub 명령어 도움말을 바로 확인할 수 있습니다.
- Knox에서 `/skillhub list` 또는 `/skillhub list <category>`로 공유 스킬 목록을 카테고리별로 확인할 수 있습니다.
- Knox에서 `/skillhub installed`로 현재 workspace에 설치된 Skill Hub 스킬을 확인할 수 있습니다.

## 변경

- workspace 기본 안내에 Skill Hub 조회와 설치 현황 확인 명령어를 함께 안내하도록 보완했습니다.
- 에이전트가 현재 시각이 필요한 요청을 처리할 때, 채팅 경로별 시간 기준이 더 일관되게 전달되도록 개선했습니다.

## 수정

- WebChat과 Control UI 채팅에서 에이전트가 예약 작업을 만들거나 조회할 때, 불필요한 연결 승인 흐름으로 막히는 상황을 줄였습니다.
- 예약 작업의 생성, 수정, 삭제, 즉시 실행, 실행 내역 조회가 채팅에서 더 안정적으로 동작하도록 개선했습니다.
