# PlatformClaw v2026.7.6

Date: 2026-07-06

## 추가

- 사용자 화면 상단에 VOC 접수 바로가기를 추가했습니다. 설정된 VOC URL이 있을 때 직원이 현재 화면에서 바로 문의/불편 접수로 이동할 수 있습니다.
- 채팅 화면에 compaction 진행 상태를 더 명확하게 보여주는 표시 흐름을 추가했습니다.

## 변경

- 사용자 화면의 좌측 탐색은 채팅과 최근 세션에 집중하고, 파일/스킬/예약 작업/관리 도구는 작업 화면의 보조 패널에서 접근하도록 정리했습니다.
- 상단 바로가기에서 Dashboard와 Skill Hub를 더 쉽게 찾을 수 있도록 사용자 화면의 주요 진입점을 정리했습니다.
- 긴 대화가 끝난 뒤 context 사용량 표시가 더 늦지 않게 갱신되도록 조정했습니다.
- compaction 뒤 이어지는 답변과 후속 메시지가 사용자에게 더 자연스럽게 이어지도록 채팅 상태 표시를 조정했습니다.

## 수정

- compaction 이후 최종 답변 이벤트가 누락되어 새로고침해야 답변이 보이는 문제를 줄였습니다.
- compaction successor reply와 hook continuation이 끊기거나 늦게 보이는 문제를 보완했습니다.
- compaction 중 heartbeat/truncation 처리와 mascot 표시 시간이 어긋나는 문제를 보강했습니다.
- 메모리/Dreaming recall 필터가 필요한 항목을 지나치게 걸러내는 문제를 수정했습니다.
- 직원 채팅 세션 목록이 갑자기 `main` 또는 일부 세션만 보이는 문제를 수정했습니다.
- 답변이 끝났는데도 `Preparing response` 상태가 남는 문제를 줄였습니다.
- 사용자 화면에서 일부 한글 문구가 깨져 보이던 문제를 수정했습니다.
- 최근 세션 목록에서 우클릭 메뉴를 열 때 세션 row가 비정상적으로 길어지는 문제를 수정했습니다.
- 최근 세션 목록을 스크롤할 때 채팅 본문이 함께 밀려 올라가는 문제를 수정했습니다.
- 새 세션 버튼과 결과물 첨부 파일 아이콘이 다크 모드에서 보이지 않거나 검게 튀어 보이는 문제를 수정했습니다.

## 내부 메모

- 이번 릴리즈는 2026-07-02부터 2026-07-06까지의 compaction/chat 상태 안정화, VOC shortcut, employee UI rail 정리 및 회귀 수정 커밋을 기준으로 작성했습니다.
- 주요 검증 포인트는 compaction 이후 답변 표시, 세션 목록 갱신, `Preparing response` 정리, employee sidebar 스크롤, 다크 모드 artifact 표시입니다.
