# PlatformClaw v2026.7.6

Date: 2026-07-06

## 추가

- 예약 작업 빠른 생성 wizard를 추가했습니다. “무엇을 실행할지”, “언제 실행할지”, “결과를 어떻게 받을지”를 단계별로 선택해 반복 작업을 더 쉽게 만들 수 있습니다.
- 예약 작업 목록에 필터와 접기 가능한 작업 패널을 반영했습니다. 많은 작업이 있어도 상태와 실행 내역을 더 빠르게 훑을 수 있습니다.
- `Dreaming` 화면에 diary/scene 기반 확인 흐름을 추가했습니다. 메모리 정리 결과를 UI에서 더 구체적으로 볼 수 있습니다.
- 메모리 검색 진단을 추가했습니다. 메모리 검색이 비어 있거나 느린 경우 원인을 더 빨리 확인할 수 있습니다.
- 사용자 채팅 세션에 이름 변경, 삭제, action menu, 세션 패널 접기/펼치기 흐름을 추가했습니다.
- WebChat 답변에 포함된 media를 채팅 화면에서 바로 볼 수 있도록 표시 경로를 추가했습니다.
- 로컬 CLI와 실제 runtime이 어긋나는 상황을 점검하기 위한 PlatformClaw 진단 문서를 추가했습니다.

## 변경

- 사용자 화면의 좌측 탐색은 채팅과 최근 세션에 집중하고, 파일/스킬/예약 작업/관리 도구는 작업 화면의 보조 패널에서 접근하도록 정리했습니다.
- 사용자 채팅 세션 목록을 더 가볍게 보이도록 다듬고, 현재 세션/활동 상태/최근 작업 상태가 더 분명하게 보이도록 정리했습니다.
- 상단 바로가기에서 Dashboard와 Skill Hub를 더 쉽게 찾을 수 있도록 사용자 화면의 주요 진입점을 정리했습니다.
- 사용자 채팅의 모델 선택 목록을 현재 사용자가 실제로 사용할 수 있는 모델 중심으로 동기화했습니다.
- 채팅 입력 중 한글/일본어 등 IME 조합 상태의 draft가 사라지지 않도록 입력 흐름을 조정했습니다.
- 긴 채팅 기록, 혼합 assistant 텍스트, stream error 뒤쪽 기록을 다루는 방식을 조정해 이전 메시지 표시가 더 안정적으로 유지됩니다.
- Cron 실행 내역과 요약 표시를 더 안전하게 렌더링하도록 바꿨습니다.
- 메모리 wiki 링크는 code block 안의 텍스트를 링크로 오인하지 않도록 처리 방식을 바꿨습니다.
- OpenAI-compatible, vLLM, Ollama thinking, OpenAI reasoning effort 등 모델 runtime 호환성 업데이트를 반영했습니다.
- provider auth alias, provider discovery, model catalog visibility 업데이트를 반영해 모델/인증 선택이 더 일관되게 동작합니다.
- Slack, Matrix, MS Teams 등 메시징 채널의 thread/session routing 관련 업데이트를 반영했습니다.
- Android/iOS pairing 및 gateway connection 문제 진단 UX 업데이트를 반영했습니다.

## 수정

- 사용자가 자기 세션만 안전하게 이름 변경/삭제할 수 있도록 범위 검사를 보강했습니다.
- 사용자 main session을 잘못 rename하는 경우를 막고, WebChat main session reset이 기존 세션 흐름을 불필요하게 흔들지 않도록 수정했습니다.
- 기본 session list 조회와 응답 크기를 제한해 세션이 많을 때 화면이 느려지는 문제를 줄였습니다.
- compaction 이후 hook continuation이 누락되거나, kept-tail prompt가 과하게 들어가거나, retry가 오래 멈춰 보이는 문제를 보완했습니다.
- subagent session retention, session lineage, subagent announce 재시도, orphan recovery 관련 동작을 보강했습니다.
- transcript append를 직렬화하고 session repair 메시지를 정리해 기록 파일이 깨지는 상황을 줄였습니다.
- media staging cleanup, reply media 표시, session image 기록 정리를 보강했습니다.
- Gateway 재연결 뒤 `/stop` 상태가 보존되지 않거나 chat status refresh가 늦어지는 문제를 줄였습니다.
- 사용량 조회에서 시작일/종료일이 뒤집힌 요청을 거부하고, pricing catalog 읽기가 과도해지는 상황을 제한했습니다.
- Skill Hub icon 정리 작업이 잘못된 gateway 범위에서 실행되지 않도록 조정했습니다.
- release note index와 runtime surface 검증을 보강해 릴리즈 노트 로딩 실패 가능성을 줄였습니다.
- 사용자 화면에서 일부 한글 문구가 깨져 보이던 문제를 수정했습니다.
- 최근 세션 목록에서 우클릭 메뉴를 열 때 세션 row가 비정상적으로 길어지는 문제를 수정했습니다.
- 최근 세션 목록을 스크롤할 때 채팅 본문이 함께 밀려 올라가는 문제를 수정했습니다.
- 새 세션 버튼과 결과물 첨부 파일 아이콘이 다크 모드에서 보이지 않거나 검게 튀어 보이는 문제를 수정했습니다.

## 내부 메모

- 이번 릴리즈는 `main` 이후 반영된 외부 업데이트 묶음과 PlatformClaw 맞춤 포팅/안정화 커밋을 함께 정리한 버전입니다.
- 주요 검증 포인트는 사용자 채팅 세션 전환/rename/delete, Cron 빠른 생성/실행 내역, Dreaming 화면, 메모리 검색, WebChat media 표시입니다.
- 브랜치 범위가 넓어 채널 routing, provider/model auth, 모바일 pairing 업데이트는 회사 배포 환경에서 smoke test가 필요합니다.
