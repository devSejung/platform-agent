# PlatformClaw v2026.6.25

Date: 2026-06-25

## 추가

- PlatformClaw 사용량 추이를 한 화면에서 볼 수 있는 `Dashboard`를 추가했습니다.
- 검색창 옆 `Dashboard` 버튼으로 바로 사용량 화면에 들어갈 수 있습니다.
- `Today`, `7 days`, `30 days`, `Total` 필터를 통해 기간별 사용량 변화를 확인할 수 있습니다.
- `Active Agents`, `Sessions`, `API Calls`, `Total Tokens` 요약 카드와 함께 기간별 token 추이 차트를 볼 수 있습니다.
- 파트별 활용 현황과 Agent별 활용 현황을 각각 나눠 확인할 수 있습니다.

## 변경

- Dashboard 상단 구조를 usage overview 중심으로 재구성해, PlatformClaw 사용량 추이를 더 빠르게 읽을 수 있도록 정리했습니다.
- `Daily Token Usage` 차트는 선택한 기간 안에서 실제 사용량 차이가 더 분명하게 보이도록 표현을 개선했습니다.
- Agent별 활용 현황 표는 이름, 파트, Agent, API 호출 수, token 사용량, 마지막 사용 시점을 더 읽기 쉽게 정리했습니다.
- PlatformClaw 활용 추이를 한눈에 보기 쉽도록 표와 요약 패널 구성을 정돈했습니다.

## 수정

- Dashboard 버튼을 눌러도 화면 전환이 되지 않던 문제를 수정했습니다.
- account metadata와 usage 데이터를 연결하는 방식을 보완해 이름과 part가 더 안정적으로 표시되도록 개선했습니다.
- part 정보가 연결되지 않은 항목이 있어도 Dashboard 전체가 깨지지 않고 `Unassigned`로 묶여 보이도록 처리했습니다.
- sparkline, usage peak, table 정렬선, topbar 버튼 등 Dashboard UI의 어색한 배치와 시각 밀도를 여러 구간에서 다듬었습니다.

## 내부 메모

- 비용, prompt, transcript, raw log, error detail, session drill-down, skill usage 추적은 이번 Dashboard V0 범위에서 제외했습니다.
- `Total` 기간 집계는 성능 보호를 위해 1시간 TTL cache를 사용합니다.
